# Illegal-Soccer.com - Architecture & SEO/GEO Specification

## 1. Overview
- **Domain**: `illegal-soccer.com`
- **Target Topic**: Roblox viral sports brawl game *Illegal Soccer* (mechanics, controls, curve shots, item tier lists, codes, ranked).
- **Deployment**: Static site (HTML5 / Vanilla CSS / Vanilla JS) on Cloudflare Pages.
- **GitHub Repository**: `https://github.com/oprom0004/illegal-soccer.com` (branch: `master`).

## 2. URL Cluster & Single-Level Sitemap
1. `https://illegal-soccer.com/` - Master Hub, Controls cheat sheet, Ranked unlocks, and Interactive Curve Simulator.
2. `https://illegal-soccer.com/how-to-curve/` - Dedicated How to Curve Shot & Ball Bend Guide (PC & Controller).
3. `https://illegal-soccer.com/tier-list/` - Complete Item & Weapon Tier List (S to D Tier with tactical loadouts).
4. `https://illegal-soccer.com/codes/` - Codes Status, Verification report, and legitimate coin farming methods.

## 3. SEO & GEO Features
- **GEO Direct Answer Blocks**: Concise, factual summary lists structured for Google AI Overviews and Perplexity extraction.
- **Schema.org JSON-LD**: Comprehensive `WebSite`, `Article`, `HowTo` (curve steps), `FAQPage`, and `BreadcrumbList` markup on every page.
- **Instant Preloading**: Custom hover & touch prefetcher in `app.js` for sub-100ms page transitions.
- **Visual Design**: Stadium dark neon theme, zero AI cliches, high accessibility and responsive tables.
